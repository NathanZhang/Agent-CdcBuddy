# 意图分析与调度功能重构及 AG-UI 动态组件升级方案

为了彻底解决用户在复合指令（如“显示数据并计算平均数”）和多轮上下文对话（如“计算上述数据的平均数”）中，系统只会返回原始表格且无后续计算、无结论反馈的问题，我们将重构整个意图分析与路由逻辑，将其升级为完全基于大模型 Tool Use 的智能体闭环控制流（Agent Tool Use Loop），并升级 AG-UI 组件实现动态的聚合分析与可视化卡片渲染。

## 主要变更内容

1. **移除静态规则拦截与短路逻辑**：
   - 彻底清理 `llm-router.ts` 中前置的静态 regex 意图拦截（如 `isMultiStepChain`、`isDataQueryVerb` 等），将控制权完全移交给大模型的 Function Tooling，实现完全灵活的意图识别。

2. **构建 BFF 服务端 Tool Use 循环（Agent Loop）**：
   - 在 `/api/agent/dispatch` 接口中，支持 LLM 的工具链调用。
   - 当大模型决定调用 `skill_monitoring_data_table`（数据查询）等技能时，在服务端实时执行，并对结果数据进行**轻量化摘要（Summary + 样本数据）**，以 `tool` 角色消息的形式喂回给大模型。
   - 再次调用大模型生成最终的自然语言总结答复（包含均值、总量等具体计算结论）。

3. **支持多轮上下文数据与“上述指代”解析 (Anaphora Resolution)**：
   - 接口在接收到包含“上述/该表/当前”且涉及“计算/统计”的请求时，自动提取前端当前视图的 `context.currentView.data`，将数据量、字段结构及核心统计学数据（Avg, Sum, Max, Min）作为系统提示词/临时上下文注入到大模型输入中。
   - 大模型看到当前工作台数据上下文后，无需重复检索数据库即可秒级给出精准的计算答案与洞察。

4. **升级前端 `DataTableComponent`（AG-UI 可视化卡片）**：
   - 在表格上方新增动态、高质感、高颜值的 **统计摘要指标卡片 (KPI cards)**：显示样本总量、平均捕获数、捕获总量、最高单点值、平均气温/湿度。
   - 增加交互微动画和渐变色卡片，让结果输出从简单的纯表格升级为高级智能体的“生成式数据大屏”。
