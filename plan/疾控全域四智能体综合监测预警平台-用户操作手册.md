## 一、平台总体架构与工作范式

### 1.1 平台定位与四智能体协同矩阵

CdcBuddy 平台面向省级疾病预防控制中心业务场景，依托通用 LLM 底座、科学计算算法中台（`analytics_engine`）及统一交互界面（CopilotKit + AG-UI 生成式组件），构建覆盖公共卫生四大核心领域的智能体矩阵：

| 智能体标识 | 业务应用全称 | 核心业务所处业务科室 | 独立端口 | 路由网关 | 事实数据底座 |
| :--- | :--- | :--- | :---: | :---: | :--- |
| **`vector`** | 病媒生物与宿主动物监测预警智能体 | 消毒与媒介生物控制所 | `3001` | `/vector/` | `vector_monitoring.db` |
| **`foodborne`**| 食源性疾病监测预警智能体 | 食品安全与营养卫生所 | `3002` | `/food/` | `foodborne_monitoring.db` |
| **`env`** | 环境健康风险监测预警智能体 | 环境与健康所 | `3003` | `/env/` | `env_monitoring.db` |
| **`chronic`** | 死因、慢病及伤害综合监测预警智能体 | 慢性非传染性疾病防制所 | `3004` | `/death/` | `chronic_monitoring.db` |

### 1.2 统一界面工作台结构与交互范式

每个智能体页面均包含标准化功能区布局：
1. **顶部态势看板（Header & Metrics Bar）**：
   - 实时展示当前智能体核心资产统计（如“监测记录量”、“PCR/理化检测批次”、“高危暴发预警数”、“全省覆盖点位数”）。
   - 用户点击任一统计胶囊，即可将该业务主题作为提示词注入对话框。
2. **常用业务场景与推荐功能对话提示词（Recommendation Cards）**：
   - 系统为每个智能体量身配置 **4 大类、共 12 条高频精选业务卡片**。
   - 点击任一卡片，即可一键下发指令，驱动底层算法引擎并在右侧生成专属交互式 AG-UI 视窗。
3. **自然语言对话流与 Copilot 交互区（Chat Panel）**：
   - 支持多轮对话、流式打字机输出、专业参数追问、Text2SQL 数据钻取与知识库检索。
4. **生成式动态工作台（AG-UI Generative Canvas）**：
   - 根据 AI 研判结果实时渲染高保真图表、GIS 热力等值面、分子系统发育树、时空雷达、决策树及处置工单。
5. **历史会话与数据回溯抽屉（Session Drawer）**：
   - 记录每次交互上下文，支持一键载入历史会话与处置复核。

### 1.3 三大交互驱动模式

- **模式 1：场景卡片即时联动**：点击“常用业务场景”卡片，系统自动加载预置参数并运行对应 Skills。
- **模式 2：指标胶囊穿透钻取**：点击顶部 Metrics 栏的特定指标，联动查询全省地市明细报表。
- **模式 3：自由自然语言交互**：在底部指令输入框中输入专业指令（如“请分析平顶山市2024年水质超标情况并给出管网冲洗建议”），系统通过意图识别智能派发至特定算法引擎。

## 二、（二）病媒生物与宿主动物监测预警智能体实操指南（No. 23 ~ 35）

### 2.1 种群动态分析（No. 23 ~ 24）
- **功能描述**：
  - **No. 23 种群动态模型**：采用 ARIMA 与 LSTM 时间序列模型，预测蚊、蝇等密度未来 3 个月波动曲线，模型平均误差率 $\le 10\%$。
  - **No. 24 种群识别模型**：通过 K-Means 聚类算法自动识别区域优势种群（如白纹伊蚊 vs 淡色库蚊构成比及空间异质性）。
- **实操步骤**：
  1. 在推荐卡片中点击【分析近几年全省蚊类密度随气温变化的季节消长规律，并预测未来3个月密度波动】；
  2. 或在对话框输入：`请利用 LSTM 模型预测郑州市未来 3 个月白纹伊蚊成蚊密度变化趋势`；
  3. **系统反馈**：右侧画布渲染 `BaseForecastTrendChart`，展示历史拟合曲线、外推 90 天预测带（带 95% 置信区间）及峰值预警窗口。

### 2.2 抗药性评估与演化预测（No. 25, 32）
- **功能描述**：
  - **No. 25 抗药性预测模型**：输入药剂类型、地理位置与历史测定数据，预测敏感/中抗/高抗耐药等级，辅助轮换用药。
  - **No. 32 抗药性演化预测**：基于历史数据与施药频次，利用贝叶斯网络模型预测未来 1 年抗药基因频率变化。
- **实操步骤**：
  1. 点击推荐卡片【评估全省淡色库蚊对氯氰菊酯和残杀威的抗药性等级及用药调整建议】；
  2. 对话框追问：`请预测安阳市未来1年淡色库蚊对拟除虫菊酯类 KDR 基因频率演化趋势`；
  3. **系统反馈**：界面加载 `ResistanceMatrixChart` 抗性矩阵热力图与科学用药轮换建议单。

### 2.3 病原携带与传播风险分析（No. 26, 31）
- **功能描述**：
  - **No. 26 病原携带风险评估**：通过 Apriori 关联规则挖掘病媒病原检测与宿主分布，识别高风险组合。
  - **No. 31 传播风险评估模型**：构建“病媒密度－病原携带率－人群暴露”三元耦合模型，量化输入性或本地传染病传播风险（指数化评级 0~100）。
- **实操步骤**：
  1. 输入指令：`排查全省蚊媒登革病毒与乙脑病毒的 PCR 阳性检出率及高风险区县`；
  2. **系统反馈**：渲染 `TransmissionRiskGauge` 传播风险仪表盘与高风险宿主地理分布图。

### 2.4 动态预警响应与处置闭环（No. 27 ~ 29）
- **功能描述**：
  - **No. 27 动态预警分析**：常规阈值与极端天气多维触发，响应时间 $\le 15$ 分钟，GIS 热力图支持下钻至街道级。
  - **No. 28 预警推送信息**：自动按一般（黄）、较重（橙）、严重（红）三级分类推送，附带触发依据与置信度。
  - **No. 29 处置闭环信息**：智能生成防控措施（如“清除积水 + 超低容量空间喷雾”），提供 48 小时处置进度跟踪与核销闭环。
- **实操步骤**：
  1. 点击推荐卡片【在地图上展示全省当前的病媒生物预警热力分布，标记所有严重（红色）预警区域】；
  2. 点击地图上的红色预警点（如“郑州市金水区”）；
  3. 在弹出的 `BaseDisposalWorkflowCard` 中点击【生成应急派单】，确认消杀队伍与药剂配比，工单状态由“待处置”进入“处置中”。

### 2.5 密度预测模型（No. 30）
- **功能描述**：融合温湿度、降水等气象数据与地理生境，通过梯度提升回归树（GBDT）预测未来 1~2 个月病媒生物密度。
- **实操步骤**：在输入框发送 `结合本周强降水气象，通过 GBDT 模型预测下月豫南地区成蚊密度峰值`，系统即时输出地市级密度增长倍数。

### 2.6 自然语言问答与专题研判报告（No. 33 ~ 34）
- **功能描述**：
  - **No. 33 自然语言问答（NLQ）**：内置消毒媒介控制规范与种类鉴别标准，提问响应时间 $\le 2$ 秒。
  - **No. 34 专题报告信息**：自动提炼重点指标、生成文字分析，支持一键导出 Markdown 或 PDF 研判专报。
- **实操步骤**：
  1. 问答提问：`白纹伊蚊幼虫与淡色库蚊幼虫在呼吸管形态上有何区别？`，系统 2 秒内返回标准图解定义；
  2. 报告生成：点击推荐卡片【生成郑州市2024年夏季蚊媒监测与登革热风险评估专项报告并准备导出】，在右侧 `BaseReportViewer` 中预览并点击【一键导出 PDF】。

### 2.7 移动端智能辅助接口（No. 35）
- **功能描述**：系统后台暴露 RESTful API，供疾控移动端 APP 调用现场拍照图像识别虫媒种类、自动填报经纬度并校验逻辑完整性。
- **接口指引**：开发人员及现场流调员通过统一网关访问 `/api/v1/vector/species-recognize` 完成图像上传识别。

## 三、（三）食源性疾病监测预警智能体实操指南（No. 36 ~ 41）

### 3.1 聚集性病例识别模型（No. 36）
- **功能描述**：利用 SaTScan 空间-时间-主诉症状圆柱扫描算法，实时比对全省哨点医院门诊主诉与就诊地址，自动标记短期内可疑聚集性事件，支持弹性动态预警阈值设定。
- **实操步骤**：
  1. 访问食源性智能体页面（端口 `3002`，路径 `/food/`）；
  2. 点击推荐卡片【排查全省近7天哨点医院食源性病例异常激增，标记所有时空聚集性暴发事件】；
  3. **系统反馈**：右侧渲染 `FoodborneClusterRadar`，高亮显示出郑州高校食堂（副溶血性弧菌）、洛阳婚宴（沙门氏菌）等聚集性圆柱聚类群。

### 3.2 发病风险与扩散预测模型（No. 37）
- **功能描述**：融合历史病例数据、夏秋季气象与人口流动特征，利用 LSTM 神经网络预测未来 4 周高发致病菌与区域扩散风险等级。
- **实操步骤**：
  1. 点击推荐卡片【结合夏季气象与历史基线，利用 LSTM 模型预测未来 4 周全省沙门氏菌感染发病趋势】；
  2. 系统返回未来 4 周预测曲线，并根据郑州、商丘等交通枢纽人流评估跨市扩散概率。

### 3.3 致病菌分子溯源与传播链构建（No. 38）
- **功能描述**：基于 cgMLST（核心基因组多位点序列分型）等位基因差异矩阵计算汉明距离（差异位点 $\le 5$ 标记同源聚类），结合病例饮食暴露与农贸批发供应链知识图谱，绘制传播链拓扑树。
- **实操步骤**：
  1. 点击推荐卡片【对比郑州与开封两起病例分离出的单增李斯特菌 cgMLST 等位基因相似度，判定是否同源】；
  2. **系统反馈**：右侧展示 `MolecularPhylogenyTree` 分子进化树，可视化展示两地菌株等位基因差异仅为 1 个位点，判定为同源冷链熟食污染事件。

### 3.4 自动生成标准化处置建议与工单派发（No. 39）
- **功能描述**：针对检出事件自动推送标准流调规范，涵盖食物留样封存、环境涂抹采样指南，并推荐历史相似成功处置案例。
- **实操步骤**：
  1. 在聚集性事件卡片中点击【启动现场处置】；
  2. 界面加载 `OutbreakEpidemiologyCard`，显示标准化流行病学调查表清单（就餐者排查、后厨厨工便检、食材留样送检），并自动同步至地市疾控工单池。

### 3.5 动态监测大屏与高风险食品排行榜（No. 40）

## 四、（四）环境相关风险因素监测预警智能体实操指南（No. 42 ~ 58）

  - **No. 62 死亡图谱识别**：运用 ARIMA 时序趋势分析与 DBSCAN 空间高密度聚类，圈定高死亡风险区域。
  - **No. 63 罕见死因检测**：对极低发生率死因进行实时扫描，当某一区县短期内出现 $\ge 3$ 例同类罕见死因时触发警报。

  2. **系统反馈**：渲染 `ICD10InferenceCard`，图谱化展示推导链路（例如：严重肺部感染 $\leftarrow$ 长期卧床 $\leftarrow$ 股骨颈骨折，根本死因为意外跌倒引起的骨折）。

- **实操步骤**：
  1. 点击推荐卡片【利用 GBDT 风险模型预测全省各区县未来 3 年恶性肿瘤与脑卒中发病率时空演变】；
  2. 点击推荐卡片【基于各区县肿瘤高发数据与人口老龄化系数，生成高危人群早癌筛查推荐清单与卫生经济学收益】；
  3. **系统反馈**：输出筛查推荐清单与投入产出比雷达图。

### 5.4 伤害病例时空聚类、决策树归因与聚集识别（No. 67 ~ 69）
- **功能描述**：
  - **No. 67 伤害类型聚类**：对门诊伤害病例进行聚类，识别高发类型与时空特征（如老年居家跌倒、学龄儿童上下学交通伤害）。

  - **No. 69 聚集性事件识别**：同一单位或场所短期内出现 $\ge 5$ 例同类伤害时，系统自动判定为聚集性事件并启动溯源。
- **实操步骤**：

  2. 点击推荐卡片【构建决策树模型分析农村地区农机操作伤害的主要风险因素归因比】；
  3. **系统反馈**：右侧画布加载 `InjuryDecisionTreeCard`，可视化呈现伤害诱因归因树分支。

### 5.5 预警三级触发与省市县分级定向推送（No. 70 ~ 71）

### 5.6 综合公报生成与简略寿命表（No. 72 ~ 73）

### 5.7 死因、慢病与伤害分类精准干预（No. 74 ~ 76）

### 6.2 运维控制命令 (`server.sh`)

系统在根目录下提供了统一运维脚本 `server.sh`，支持单个或全量服务启停：

```bash
# 1. 启动全量智能体集群 (开发环境 / 生产环境)
./server.sh start all dev
./server.sh start all prod

# 2. 启动特定领域智能体
./server.sh start env dev         # 启动环境健康智能体 (Port 3003)
./server.sh start vector prod     # 启动病媒生物智能体 (Port 3001)

# 3. 检查全量智能体运行状态矩阵
./server.sh status

# 4. 停止指定智能体或全量停止
```
