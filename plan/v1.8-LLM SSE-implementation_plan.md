# Implementation Plan - LLM 动态推理 (Thinking) 过程流式显示与思维链交互改造

为 Agent-CdcBuddy 疾控病媒生物监测预警智能体实现大模型深度思考与推理过程（Thinking / Reasoning Process）的动态流式显示、打字机动效、实时耗时秒表与思维链交互折叠组件。

## User Review Required

> [!IMPORTANT]
> 1. 本次改造将把客户端调度升级为流式 SSE（Server-Sent Events）模式，通过 `/api/agent/stream-dispatch` 实时接收 LLM 的 `reasoning_chunk`、`content_chunk` 与 `tool_calls` 执行状态。
> 2. 兼容多种 LLM 推理格式：包括 DeepSeek-R1 / Qwen3.6 的 `delta.reasoning_content` 以及开源模型的 `<think>...</think>` 标签流式解析。
> 3. 支持用户随时点击“停止”中断流式推演，同时支持思考过程的持久化与历史会话完整回放。

---

## Proposed Changes

### 1. 服务端流式端点与协议适配 (BFF Stream Engine)

#### [NEW] [src/app/api/agent/stream-dispatch/route.ts](file:///Users/nathanzhang/Documents/DEV/AI-CDC/Agent-CdcBuddy/src/app/api/agent/stream-dispatch/route.ts)
- 实现基于 SSE (`text/event-stream`) 的流式接口。
- 支持大模型 `stream: true` 模式下的双阶段执行（第1阶段：意图识别与推理/Tool Calling；第2阶段：Tool 执行并总结）。
- 实时向客户端分发 `reasoning_start`, `reasoning_chunk`, `reasoning_end`, `tool_call_start`, `tool_call_result`, `content_chunk`, `generative_view`, `finish`, `error` 事件。
- 深度兼容 `delta.reasoning_content` 与 `<think>` 标签混合流。

## Verification Plan

### Automated Tests
- 运行工程构建与类型检查：`npm run build` 或 `npx tsc --noEmit`。
- 验证 API 端点和数据落库接口。

### Manual Verification
1. 启动项目，在输入框发送研判指令（如：“分析郑州市金水区白纹伊蚊密度及防控措施”）。
2. 观察智能体输出：
   - 思考阶段：出现带有脉冲动画与秒表计时的 ThinkingProcessCard，推导演变文本实时流式打印。
   - 结论阶段：ThinkingProcessCard 自动折叠，下方平滑流式输出最终研判报告与生成式图表。
3. 点击折叠栏，验证能否正常展开/收起思维链。
4. 测试在推导过程中点击“停止”，验证能否立即打断流。
5. 刷新页面或切换历史会话，验证思维链记录是否能完整回放还原。
