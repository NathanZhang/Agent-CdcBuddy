# 疾控病媒监测预警智能体系统 (CdcBuddy Vector Guard) 整体设计方案与开发计划 (v1.2)

本项目面向疾控中心（CDC）病媒生物（蚊、蝇、鼠、蟑、蜱、恙螨）及宿主动物生态监测、病原检测、抗药性评估、动态预警与处置闭环，基于 **CopilotKit** 框架构建智能体应用。系统原生支持 **AG-UI 生成式界面**（含空间地理地图组件、专业时空图表、交互式数据表格与动态处置卡片），采用**全量业务 Skills 插件化架构**，支持用户通过对话自主创建与扩展技能，并提供独立应用运行与嵌入式浮窗双模式。

---

## 一、 专项技术评估与架构决策

### 1. 数据库选型与生产环境信创迁移架构 (SQLite -> PostgreSQL / 人大金仓 KingbaseES)
* **评估与架构决策**：
  1. **当前开发与测试阶段**：统一采用治理完毕的 SQLite (`vector_monitoring.db`) 作为单一数据库引擎，实现极速查询与零外部依赖部署。
  2. **生产环境信创适配设计 (Repository 抽象隔离层)**：
     - 构建统一的数据库抽象层 `IVectorDataProvider` 与标准 SQL 方言适配器（Dialect Adapter）。
     - 业务层与 Skills 执行器统一面向接口调用，不直接耦合底层驱动。
     - **支持无缝平滑迁移**：生产环境只需切换配置连接串，即可一键迁移至 **PostgreSQL** 或国产信创数据库 **人大金仓 (KingbaseES)**，SQL 语句遵循标准 ANSI SQL-92/99 规范，并提供 DDL 迁移脚本与表映射工具。

### 2. 业务功能全量 Skills 化封装评估与方案
* **评估结论**：**强烈推荐并全面实施《功能清单》23~35 项业务的全量 Skills 化封装**。
* **设计方案**：
  - 将种群动态分析、抗药性评估、病原携带风险、动态预警处置、中长期预测、自然语言问答、自动报告生成、移动端数据辅助等功能全部标准化为 **VectorSkill 实体**。
  - **核心优势**：
    1. **高度解耦与可插拔**：每个 Skill 具备自包含的入参校验 (JSON Schema)、业务计算逻辑与专属 AG-UI 渲染器。后续增加新模型只需注册新 Skill。
    2. **自主对话定制能力 (Meta-Skill)**：用户通过自然语言提出的个性化分析诉求，可由系统动态组装为新的 Skill 并持久化至技能库，与官方预置 Skill 享受同等调度能力。
    3. **细粒度 RBAC 授权**：每个 Skill 可灵活绑定角色权限（如高级预警下发仅限省级管理员，抗药性测定仅限市级专家）。
    4. **双模式与跨端复用**：同一个 Skill 既服务于独立版界面，也无缝通过 API 服务于移动端与第三方嵌入式业务系统。

|  * 生产迁移支持: PostgreSQL / 人大金仓 (KingbaseES) 信创环境 DDL 与驱动无缝切换   |
|  * CDC 知识库: 国家病媒生物监测规范、消杀用药指南、空间行政区划 GeoJSON 数据       |
+-----------------------------------------------------------------------------------+

| **风险预测** | `skill_transmission_risk` | **No. 31** 传播风险评估模型| 构建"病媒密度－病原携带率－人群暴露"关联量化模型，输出综合传播风险指数 | 传染病传播风险综合评估仪表盘 |

## 四、 页面交互设计与双模式运行架构

### 1. 独立运行模式 (Standalone Mode - 第一阶段全功能)
- **初始探索界面 (Home View)**：
  - 顶部：疾控中心病媒生物监测综合态势指示条（河南省 18 市监测点状态、活跃预警数、主要超标物种）。
  - 中部：精选推荐 Prompt 瀑布流卡片（按"预警排查"、"抗药性评估"、"专项分析"、"报告生成"分类）与 Skills 技能大厅。
  - 角色切换器（RBAC Switcher）：支持一键切换【省级管理员 / 市级专家 / 区县监测员 / 公众访客】以实时预览权限边界。
- **对话与 AG-UI 工作台 (Agent Workspace)**：
  - 左侧/主区：**生成式 UI 工作台**。根据对话动态展开空间地理地图组件、ECharts 趋势图、数据表格、处置工单或生成的专题报告。
  - 右侧/协同区：**Copilot 智能交互对话区**。展示推理思考链、推荐后续追问、支持语音/文本输入与技能快捷调用。

### 2. 嵌入式浮窗与 API 模式 (Embedded Widget & Open API)
- 提供 `<CdcBuddyWidget />` 悬浮助手组件与免编译嵌入脚本 `cdc-buddy-embed.js`，支持以浮窗形式嵌入 CDC 现有业务系统。
- 开放 `/api/v1/mobile/*` 接口，提供完善的接口文档与示例代码。
