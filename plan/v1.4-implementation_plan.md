# 病媒生物监测预警智能应用全量真实功能开发方案与实施计划

## 概述

本项目基于 `Agent-CdcBuddy-DataMock/vector_monitoring.db` 现有的 **5.6万+ 条多维病媒生态监测事实表、病原体检测表与抗药性测定表**，全面替换现有前端及服务端的 Mock/假数据与伪算法，构建一套**完全由真实数据驱动、具备真实科学计算与机器学习推断能力**的疾控病媒生物监测预警智能体系统。

## 逐项功能真实落地技术方案 (序号 23 ~ 35)

### 1. 种群动态模型 (No. 23)
- **技术方案**：
  - 数据源：`fact_monitoring` + `dim_date` 按月/按旬聚合的平均捕获密度、气温、湿度时序。
  - 模型实现：利用 Python `statsmodels.tsa.arima.model.ARIMA` 或 `SARIMAX`，以气温和湿度作为外生变量（Exogenous Variables），对历史序列进行自回归拟合。
  - 输出指标：未来 1~3 个月真实预测曲线、95% 置信区间上下限（Lower/Upper Bounds）、真实计算的拟合优度 $R^2$ 与检验误差率。

### 2. 种群识别模型 (No. 24)
- **技术方案**：
  - 数据源：各区县、生境、月份下的多物种捕获量特征矩阵。
  - 模型实现：采用 `sklearn.cluster.KMeans` 对病媒群落空间分布进行聚类，自动判定优势种群特征与生态分布聚集簇。
  - 输出指标：各物种真实构成比、各市空间分布差异、Shannon-Wiener 多样性指数、K-Means 聚类中心与群落画像。

### 3. 抗药性预测模型 (No. 25)
- **技术方案**：
  - 数据源：`fact_insecticide_resistance` 中的 LC50、校正死亡率、药剂类型、地理坐标及历史年度。
  - 模型实现：训练 `RandomForestClassifier` 或 `GradientBoostingClassifier`，以药剂类型、区县、历史死亡率趋势为特征，预测目标物种对特定药剂的耐药等级（敏感/低抗/中抗/高抗）。
  - 输出指标：真实预测耐药等级、预测置信度概率分布，并根据耐药等级自动匹配国家《抗药性治理指南》轮换药剂。

### 4. 病原携带风险评估模型 (No. 26)
- **技术方案**：
  - 数据源：关联 `fact_pathogen_detection`、`fact_monitoring` 与 `dim_species`、`dim_environment`。
  - 模型实现：运行 `mlxtend.frequent_patterns.apriori` 或 `fpgrowth`，挖掘 “【物种=白纹伊蚊】+【生境=居民区】+【季节=夏季】 $\rightarrow$ 【登革病毒=阳性】” 的高风险频繁项集与关联规则。
  - 输出指标：真实 Support（支持度）、Confidence（置信度）、Lift（提升度）排序列表，精准识别高危宿主-病媒-病原组合。

### 5. 动态预警分析与 GIS 空间插值 (No. 27)
- **技术方案**：
  - 数据源：`fact_monitoring` 中带经纬度的实时监测点位数据。
  - 模型实现：基于 `scipy.spatial` 实现 **IDW（反距离加权插值）** 算法，在全省及各市网格上生成连续平滑的密度与风险栅格热力矩阵；结合三级阈值（黄/橙/红）自动过滤街道级预警点。
  - 输出指标：空间插值热力网格、街道级预警点位列表、受影响人口真实空间叠加计算。

### 6. 预警推送信息与通道集成 (No. 28)
- **技术方案**：
  - 数据源：动态预警引擎触发的结构化预警事件。
  - 实现：按风险等级（一般/较重/严重）匹配分级推送策略；提供标准 Webhook / 仿真推送日志流，记录短信网关 payload、移动端 Push 消息体与预警依据。

### 7. 处置闭环流转引擎 (No. 29)
- **技术方案**：
  - 数据持久化：在 SQLite 中新建 `fact_disposal_tickets`（工单号、预警ID、辖区、消杀措施、执行队伍、状态流转时间轴、前后 BI 复测数据）。
  - 业务状态机：支持 `待派发 (PENDING)` $\rightarrow$ `处置中 (IN_PROGRESS)` $\rightarrow$ `复测评估 (EVALUATING)` $\rightarrow$ `自动核销/闭环 (RESOLVED)`。
  - 处置建议生成：根据预警物种与生境类型，自动关联国家标准库中的处置方案，并支持前端一键派单与推进工单状态。

### 8. 密度预测 GBDT 模型 (No. 30)
- **技术方案**：
  - 数据源：构建包含滞后 1~2 期密度、旬平均气温、降雨天数、相对湿度、生境绿化率的特征工程数据集。
  - 模型实现：采用 `sklearn.ensemble.HistGradientBoostingRegressor` / `lightgbm` 训练密度回归模型。
  - 输出指标：真实模型预测未来 1~2 个月密度、特征重要性排序（Feature Importance 真实权重贡献占比）。

### 9. 传染病传播风险评估模型 (No. 31)
- **技术方案**：
  - 数学模型：构建多因子定量传播风险指数：
    $$RiskScore = 100 \times \left( w_1 \cdot \tilde{D} + w_2 \cdot \tilde{P} + w_3 \cdot \tilde{E} + w_4 \cdot \tilde{C} \right)$$
    其中 $\tilde{D}$ 为归一化病媒密度指数，$\tilde{P}$ 为病原阳性率，$\tilde{E}$ 为常住人口密度指数，$\tilde{C}$ 为气温降雨适宜度指数。
  - 输出指标：各区县多维雷达图分解得分、传播风险等级划分、驱动因子归因分析。

### 10. 抗药性演化贝叶斯预测模型 (No. 32)
- **技术方案**：
  - 数学模型：基于历史年度抗性倍数与药剂使用频次，构建**马尔可夫转移概率与贝叶斯更新模型**，推算抗性基因（如 KDR 击倒抗性突变等位基因）在未来 1 年内的频率演变趋势。
  - 输出指标：未来各年度基因频率预测曲线、抗性倍数增长上限、耐药暴发预警期。

### 11. 自然语言问答 RAG 知识库检索 (No. 33)
- **技术方案**：
  - 知识库构建：录入《GB/T 23797 病媒生物密度监测方法》《登革热媒介伊蚊应急控制指南》等标准文本。
  - 检索增强：基于 BM25 / 轻量文本 Embedding + 语义相似度召回最相关的标准条款，注入大模型 Prompt，实现精准溯源与专业问答，响应时间 $\le 2$ 秒。

### 12. 专题报告自动撰写引擎 (No. 34)
- **技术方案**：
  - 数据提取：后端动态统计选定区域/周期的全量数据（捕获总量、同比环比、优势物种排名、抗药性监测结果、高风险预警点位）。
  - 内容生成：将真实统计聚合 JSON 注入大模型报告撰写 Prompt，大模型按章节自动撰写深度研判文字，结合前端 ECharts 图表，支持一键导出 Markdown / PDF / Word。

### 13. 移动端智能辅助与数据闭环 (No. 35)
- **技术方案**：
  - 物种图像识别：接入 Vision 大模型 API（如 Qwen-VL），对上传的蚊/蝇/蟑/鼠/蜱现场照片进行形态学特征多标签识别与置信度打分。
  - 现场数据入库：`POST /api/v1/mobile/record` 接口真正执行 SQLite `INSERT INTO fact_monitoring`，实时写入并更新空间地图。
  - 实时质控校验：结合气温物理阈值与生境历史分布区间，进行多规则联动校验。

## 架构与代码修改计划

### 1. 新增 Python 科学计算与模型推断服务
- `analytics_engine/`：
  - `server.py`：基于 FastAPI 或轻量 HTTP 服务的微服务（或 Next.js 调用的独立 CLI 服务）。
  - `models/population_dynamics.py`：ARIMA/SARIMAX 时序预测。
  - `models/species_clustering.py`：K-Means 优势种群聚类。
  - `models/resistance_ml.py`：随机森林抗药性预测与贝叶斯演化模型。
  - `models/pathogen_apriori.py`：Apriori 频繁项集与关联规则挖掘。
  - `models/density_gbdt.py`：GBDT 多因子密度回归模型。
  - `models/spatial_interpolation.py`：IDW GIS 空间插值与连续网格计算。
  - `models/transmission_risk.py`：四因子归一化定量传播风险评估。
  - `models/rag_knowledge.py`：标准规范 RAG 检索器。

### 2. 数据库扩展
- 增加 `fact_disposal_tickets` 表（处置工单流转）。
- 增加 `kb_standards` 表 / 向量索引。
- 支持新监测记录真实 `INSERT` 与事务提交。

### 3. 后端 API 与技能注册改造
- 修改 `src/lib/skills/registry.ts`：将全部技能的执行逻辑对接至真实的 Python 算法引擎或 SQLite 扩展查询。
- 修改 `src/lib/db/sqlite-provider.ts`：补充工单读写、真实统计聚合与动态 SQL 接口。
- 修改 `src/app/api/v1/mobile/*`：接入真实 Vision 识别模型、真实入库与全量质控。

### 4. 前端 UI 组件升级
- 升级 `AutoReportViewer`、`DisposalWorkflowCard`、`TransmissionRiskGauge`、`ResistanceEvolutionChart`、`MobileSimulationModal` 等，使其完全接收后端真实算法与数据流。

1. **算法单元测试**：
   - ARIMA 时序预测误差率与置信区间覆盖率测试；
   - K-Means 聚类轮廓系数与构成比一致性核对；
   - GBDT 特征重要性与残差分布检验；
   - Apriori 关联规则挖掘置信度与提升度校验。
2. **端到端业务流测试**：
   - 触发“郑州市白纹伊蚊密度超标预警” $\rightarrow$ 自动派发处置工单 $\rightarrow$ 模拟现场消杀与复测 $\rightarrow$ 验证工单自动核销；
   - 移动端上传现场图片 $\rightarrow$ 触发 Vision 识别物种 $\rightarrow$ 提交入库 $\rightarrow$ 空间地图实时刷新呈现；
   - 自然语言提问 “查询登革热布雷图指数控制标准” $\rightarrow$ 验证 RAG 召回精准度。
