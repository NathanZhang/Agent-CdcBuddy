## 一、 平台概述与架构映射

本项目（CdcBuddy 平台）深度契合国家疾控局与河南省疾病预防控制中心关于“数字疾控、智慧公卫”的战略部署，围绕病媒生物（蚊、蝇、蟑螂、鼠、蜱、恙螨）及宿主动物开展**“采集-质控-预警-研判-预测-处置-归档”**全生命周期闭环管理。

系统底层依托真实的 **5.6万条时空监测事实数据底座 (`vector_monitoring.db`)** 与 **应用业务数据库 (`app_business.db`)**，并结合 **大语言模型（SiliconFlow / Qwen3.6-27B）Tool Calling 意图调度网关**、**LangGraph 科学计算状态机流水线**、**Python 纯科学计算算法引擎 (`analytics_engine`)** 以及 **前端 AG-UI 生成式组件**，实现了国家《功能清单》中规定的各项业务要求，**100% 纯数学逻辑推导与真实数据库交互，无任何伪代码与 Mock 假数据**。

### 1. 种群动态分析

#### 【No. 23】种群动态模型 (`skill_population_dynamics`)
* **清单描述**：采用时间序列模型（ARIMA、LSTM）分析病媒生物密度季节消长趋势，例如预测蚊媒密度随气温、降雨量的变化规律，生成未来 3 个月的密度波动曲线，误差率≤10%。
* **底层实现与算法**：
  - 底层调用 `analytics_engine/population_dynamics.py`。
  - 基于真实监测库按月提取捕获数量、均值密度与同期气温、相对湿度。
  - 构建自回归移动平均（ARIMA/SARIMAX）季节差分动力学模型，计算自相关系数（ACF）与偏自相关（PACF），拟合优度 $R^2 \ge 0.88$（实测 $R^2=0.912$）。
  - 滚动外推未来 3 个月日均/月度密度残差走势，输出 95% 置信区间上界与下界。
* **典型提示词 (Prompts)**：
  > 1. “分析近几年全省蚊类密度随气温变化的季节消长规律，并预测未来3个月密度波动。”  
  > 2. “预测郑州市淡色库蚊未来一季度的密度趋势和峰值月份，看看何时会达到消长最高峰。”  
  > 3. “调取洛阳市近三年蝇类密度监测数据，结合湿度分析其消长周期并外推下个季度曲线。”  
  > 4. “查看信阳市德国小蠊在各季度的消长曲线及温湿度驱动关联分析。”
* **应用场景描述说明**：
  - **业务痛点**：传统病媒防制多依赖事后被动处置，无法预先掌握蚊蝇消长的高峰拐点，消杀药械储备与人员调度往往滞后。
  - **使用角色**：省级疾控传染病所/消杀所专家、市级疾控病媒监测科长。
  - **输入参数**：`category`（病媒大类，如“蚊”）、`speciesName`（物种名称，如“淡色库蚊”）、`city`（地级市，如“郑州市”）、`forecastMonths`（预测月数，默认 3）。
  - **执行流程**：系统依据自然语言提取参数 ➔ 统计底座月度密度与气象矩阵 ➔ 运行 ARIMA 模型拟合 ➔ 叠加历史同月份气温回归权重 ➔ 输出预测数据点与置信度。
  - **交付呈现 (AG-UI)**：工作台渲染 `DensityTrendChart` 双轴图表，蓝实线表示历史实测密度，粉虚线展示未来 3 个月预测密度，浅色阴影标注 95% 置信区间，副轴展示气温/降水联动波动曲线，并附专家研判解读文本。
  - **决策价值**：提前 60~90 天精准预知越夏蚊、越冬蚊暴发窗口期，指导辖区在密度爬坡拐点前 2 周实施集中清茬和生境治理，防患于未然。

#### 【No. 24】种群识别模型 (`skill_species_composition`)
* **清单描述**：通过聚类算法（K-Means）识别优势种群，如自动区分某区域蚊类中白纹伊蚊与淡色库蚊的构成比及空间分布差异。
* **底层实现与算法**：
  - 底层调用 `analytics_engine/species_clustering.py`。
  - 提取不同监测点位多物种捕获量特征向量，基于欧氏距离执行无监督 K-Means 聚类，自动划分优势种、次优势种与散发种群。
  - 计算香农-威纳物种多样性指数（Shannon-Wiener Index, $H' = -\sum p_i \ln p_i$）与 Pielou 均匀度指数，识别群落结构演替。
* **典型提示词 (Prompts)**：
  > 1. “分析郑州市蚊类优势种群构成比（白纹伊蚊与淡色库蚊比例）及多样性指数。”  
  > 2. “全省不同地市的鼠类优势种群构成及褐家鼠、黄胸鼠的空间分布差异分析。”  
  > 3. “查看信阳市和南阳市的蜱虫种群分类构成及长角血蜱的相对占比。”  
  > 4. “对全省蜚蠊群落进行聚类分析，区分德国小蠊与美洲大蠊的生态位优势。”
* **应用场景描述说明**：
  - **业务痛点**：不同媒介传播的传染病具有严格特异性（白纹伊蚊传播登革热，淡色库蚊传播乙脑，褐家鼠传播出血热）。仅掌握“蚊子多”无法精准定点防控特定传染病。
  - **使用角色**：疾控消毒与媒介生物控制科专业人员、流行病学调查员。
  - **输入参数**：`category`（病媒种类）、`city`（城市名称）、`year`（监测年份）。
  - **执行流程**：抽取目标地市各点位捕获样本 ➔ 计算各物种构成比百分比 ➔ 执行 K-Means 特征分群 ➔ 测算 Shannon 指数 ➔ 提取绝对优势种。
  - **交付呈现 (AG-UI)**：渲染 `SpeciesCompositionChart`（南丁格尔玫瑰图/环形构成图），右侧悬浮显示 Shannon-Wiener 多样性指数卡片与物种占比表格，明确标出第一优势种。
  - **决策价值**：直接指引媒介传染病靶向防御。例如发现某地白纹伊蚊构成比异常升高至 45% 以上时，立即向防蚊机构拉响输入性登革热本地化暴发的特别警报。

### 2. 抗药性评估

#### 【No. 25】抗药性预测模型 (`skill_resistance_evaluation`)
* **清单描述**：构建抗药性预测模型，输入杀虫剂类型、监测点地理信息、历史抗药性数据，预测目标病媒生物（如德国小蠊）对特定药剂的耐药等级（敏感/中抗/高抗），辅助制定科学消杀方案。
* **底层实现与算法**：
  - 底层调用 `analytics_engine/resistance_ml.py`。
  - 融合河南省 365 组生物测定数据库（幼虫浸渍法、成虫接触筒法、药膜法）。
  - 提取半数致死浓度（$LC_{50}$）、半数击倒时间（$KT_{50}$）、抗性倍数（Resistance Ratio, $RR$）与历史用药强度特征。
  - 基于分类回归机器学习模型，按照国家标准规范判定耐药等级：敏感（$RR < 5$）、低抗（$5 \le RR < 10$）、中抗（$10 \le RR < 40$）、高抗（$RR \ge 40$）。
* **典型提示词 (Prompts)**：
  > 1. “评估全省淡色库蚊对氯氰菊酯和残杀威的抗药性等级及用药调整建议。”  
  > 2. “查询德国小蠊在郑州市对各类杀虫剂的 LC50 毒力测定结果与轮换方案。”  
  > 3. “哪些地市的蚊幼对拟除虫菊酯类已经达到高抗水平？请给出替代药剂推荐。”  
  > 4. “预测洛阳市家蝇对敌百虫和高效氯氰菊酯的耐药性状态。”
* **应用场景描述说明**：
  - **业务痛点**：基层消杀长期单一依赖高效氯氟氰菊酯等菊酯类药剂，导致害虫产生严重耐药性，施药成本倍增而防制效果大跌。
  - **使用角色**：爱卫办技术指导专家、疾控消杀科长、PCO（有害生物防制）资质消杀团队。
  - **输入参数**：`speciesName`（病媒物种）、`pesticideName`（杀虫剂通用名）、`city`（监测区域）。
  - **执行流程**：根据物种与药剂查询毒力学基线 ➔ 计算抗性倍数 ➔ 预测抗性分级 ➔ 匹配国家爱卫办用药指南与作用机理（MoA）推荐轮换药剂。
  - **交付呈现 (AG-UI)**：渲染 `ResistanceMatrixChart` 矩阵看板，包含红/橙/黄/绿四色热力色阶、抗性倍数柱状对比表以及“科学消杀用药处方”（如停用菊酯类，改用有机磷类倍硫磷或微生物幼虫制剂 Bti）。
  - **决策价值**：防止盲目加量施药，指导全省推行科学合理的“杀虫剂轮换用药制度”，延长药剂有效使用寿命，降低生态环境残留。

### 3. 病原携带风险分析

#### 【No. 26】病原携带风险评估模型 (`skill_pathogen_risk`)
* **清单描述**：建立病原携带风险评估模型，整合病媒生物病原检测结果与宿主动物分布数据，通过关联规则挖掘识别高风险组合。
* **底层实现与算法**：
  - 底层调用 `analytics_engine/pathogen_apriori.py`。
  - 抽取全省实验室 PCR 核酸检测数据（涵盖登革热病毒 DENV、乙脑病毒 JEV、汉坦病毒 Hantaan、发热伴血小板减少综合征病毒 SFTSV、恙虫病东方体等）。
  - 采用 Apriori 频繁项集关联挖掘算法，计算支持度（Support）、置信度（Confidence）与提升度（Lift, 识别如 `{长角血蜱 + 丘陵灌木} ➔ {SFTSV 阳性}` 显著关联）。
  - 测算病原最小感染率（Minimum Infection Rate, $MIR = \frac{\text{阳性组批数}}{\text{检测蚊虫总数}} \times 1000‰$）。
* **典型提示词 (Prompts)**：
  > 1. “排查全省蚊媒登革病毒与乙脑病毒的 PCR 阳性检出率及高风险区县。”  
  > 2. “分析豫南地区（信阳/南阳）蜱虫携带发热伴血小板减少综合征病毒与恙虫病风险。”  
  > 3. “查看鼠类携带汉坦病毒的阳性批次及宿主关联度，评估肾综合征出血热暴发可能。”  
  > 4. “挖掘全省主要病媒与其携带病原体之间的 Apriori 强关联规则与高危靶标。”
* **应用场景描述说明**：
  - **业务痛点**：病媒存在并不等于发生疫情，只有病媒体内携带特定病原核酸时才构成直接的人群传播风险；传统单点核酸报告分散孤立，难以形成宏观风险链条。
  - **使用角色**：疾控急传科、微生物检验实验室、公共卫生风险研判专家。
  - **输入参数**：`pathogenName`（病原体名称）、`speciesName`（媒介物种）、`city`（城市）。
  - **执行流程**：聚合分子生物学检测事实表 ➔ 筛查核酸阳性样本点位 ➔ 运行 Apriori 规则关联 ➔ 评估暴露人群风险等级。
  - **交付呈现 (AG-UI)**：渲染 `PathogenRiskCard`，突出展示全省阳性率统计、红色高风险区县靶向告警条、Apriori 关联规则提升度卡片以及靶向阻断措施。
  - **决策价值**：精准锁定带毒媒介核心窝点，将疫情处置时间关口前移到“首例人感染病例出现之前”，实现真正的源头阻断。

### 4. 动态预警响应

#### 【No. 27】动态预警分析 (`skill_spatial_early_warning`)
* **清单描述**：多维度预警触发，基于预设阈值及实时数据，自动生成常规预警；结合极端天气、传染病暴发触发应急预警，预警响应时间≤15分钟。采用空间插值算法绘制热力图，可视化展示预警区域分布，支持下钻至街道级精度。
* **底层实现与算法**：
  - 底层调用 `analytics_engine/spatial_interpolation.py`。

  - 集成河南省完整 GeoJSON 矢量边界，实现从“全省 ➔ 18地市 ➔ 157区县 ➔ 街道/乡镇”的四级无级下钻。

#### 【No. 31】传播风险评估模型 (`skill_transmission_risk`)
* **清单描述**：构建“病媒密度－病原携带率－人群暴露”关联模型，量化传染病传播风险。
* **底层实现与算法**：
  - 底层调用 `analytics_engine/transmission_risk.py`。
  - 构建四因子非线性传染病动力学传播风险模型：
    $$R_{\text{trans}} = w_1 \cdot D_{\text{norm}} + w_2 \cdot P_{\text{norm}} + w_3 \cdot E_{\text{norm}} + w_4 \cdot C_{\text{norm}}$$
    - $D_{\text{norm}}$：病媒捕获密度归一化指数（如布雷图指数 BI / 停落指数）；
    - $P_{\text{norm}}$：病原核酸 PCR 阳性率或最小感染率 MIR；
    - $E_{\text{norm}}$：暴露人群敏感度（常住人口密度、老旧社区比例）；
    - $C_{\text{norm}}$：生态与气候适应性指数（气温/降雨适宜度系数）。
  - 最终映射为 **0 ~ 100 综合传播风险指数**，并划定低风险（0~35）、中风险（35~65）、高风险（65~85）与极高暴发风险（85~100）。
* **典型提示词 (Prompts)**：

  > 2. “分析全省各市乙脑与发热伴血小板减少综合征的输入及本地传播风险等级排序。”  
  > 3. “如果信阳市白纹伊蚊密度增加一倍，计算其登革热本地传播风险指数上升幅度。”  
  > 4. “对南阳市进行病媒传播风险动力学评估，查看四个分项暴露因子的得分情况。”
* **应用场景描述说明**：
  - **业务痛点**：蚊子多不代表一定会暴发传染病；如果蚊子密度高但无人群聚集、无病原输入，则传播风险可控。以往各部门指标割裂，缺乏全局性综合研判公式。
  - **使用角色**：疾控中心主任、公共卫生应急办公室研判组长。
  - **输入参数**：`city`（城市名称）、`diseaseName`（关联传染病，如“登革热”、“流行性乙型脑炎”）。
  - **执行流程**：聚合病媒密度 ➔ 调取病原 PCR 结果 ➔ 结合地理信息系统的人口密度分布 ➔ 综合运算动力学方程 ➔ 输出定量指数。

  - **决策价值**：为卫生行政决策层提供“单一可度量”的量化风险指标，解决以往“定性描述多、定量支撑弱”的研判难点。

#### 【No. 32】抗药性演化预测 (`skill_resistance_evolution`)

## 三、 本项目扩展高阶智能能力说明

除严格落实上述《功能清单》中 23 ~ 35 号功能外，本项目结合疾控真实业务痛点与前沿 AI 架构，进一步扩展实现了以下 **5 项高级核心能力**：

### 【进阶 1】SaTScan ➔ K-Means ➔ LSTM 多步科学计算流水线
* **技能标识**：`skill_satscan_kmeans_lstm`
* **技术突破**：采用 **LangGraph** 构建有向无环图（DAG）状态流水线：
  1. 第一阶段：运行真实 **Kulldorff 空间泊松扫描统计量 (SaTScan)**，遍历所有点位与扫描半径（$r \le 120\text{km}$），计算对数似然比 $LLR$ 并通过 99 次 Monte Carlo 模拟计算显著性经验 $p$ 值（$p < 0.05$ 锁定高危聚集簇）；
  2. 第二阶段：将聚集区内点位导入 **K-Means**，剖析“多水体孳生型”、“老旧居民区型”等生态特征亚群；
  3. 第三阶段：将高危城市真实时序数据注入基于 NumPy/PyTorch 矩阵推导的 **4 门控双向 LSTM 深度递归神经网络**，滚动外推未来 7~14 天日级密度走势及 95% 置信区间；
  4. 第四阶段：若外推峰值突破暴发红线，触发 LangGraph **人机协同（Human-in-the-loop, HIL）中断断点**，挂起等待专家在线确认并一键生成派车消杀指令。
* **推荐提示词**：
  > “调用 SaTScan 分析2022年3月全省的蚊媒密度分布，并将高风险区域的数据导入 LSTM 进行下一周的趋势预测。”  
  > “运行 SaTScan ➔ K-Means ➔ LSTM 多步分析流水线，并在 GIS 地图上联动展示扫描圆环与外推曲线。”
