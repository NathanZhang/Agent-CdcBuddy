# CdcBuddy 自动化测试与质量保障指南

CdcBuddy 建立了完备的自动化测试与无 Mock 科学计算评估体系，通过 Python 自动化测试套件 (`tests/automated_test_suite.py`) 以及全量科学计算评估套件 (`tests/comprehensive_evaluation_test.py`) 对系统全量 **15 项核心与重型流水线业务技能 (Skills)**、**Meta-Skill 自定义技能动态构建引擎**、**移动端现场三级 API** 以及 **RBAC 角色鉴权安全体系** 实现了 100% 的自动化测试覆盖。

## 二、 自动化测试执行方法

### 1. 通过 NPM 脚本快速运行
```bash
npm test
```

### 2. 运行核心全量自动化测试套件
```bash
python3 tests/automated_test_suite.py
```

### 3. 运行 LangGraph / SaTScan / LSTM 深度计算评估
```bash
python3 tests/comprehensive_evaluation_test.py
```

### 4. 查看测试报告
测试完成后将在 `tests/` 目录下自动生成双格式报告：
- **Markdown 报告**：`tests/test_execution_report.md`
- **JSON 结构化报告**：`tests/test_execution_report.json`

## 四、 CI/CD 持续集成流水线配置

在 `.github/workflows/test.yml` 中集成如下测试流程：

```yaml
name: CdcBuddy Quality Assurance Test

on:
  push:
    branches: [ main, master ]
  pull_request:
    branches: [ main, master ]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20
      - name: Setup Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.10'
      - name: Install Dependencies
        run: |
          npm ci
          python -m pip install --upgrade pip
          pip install -r requirements.txt
      - name: Run Automated Test Suite
        run: |
          python tests/automated_test_suite.py
          python tests/comprehensive_evaluation_test.py
```
