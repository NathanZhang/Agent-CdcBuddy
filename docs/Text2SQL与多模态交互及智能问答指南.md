## 一、 Text2SQL 架构与安全防护中枢

CdcBuddy 提供了安全的自然语言转 SQL (Text2SQL) 查询引擎，使用户无需掌握复杂的 SQL 语法即可使用日常语言对 5.6 万条多维时空病媒监测库进行精准查询。

```
 [用户自然语言提问]
 "2024年7月郑州市金水区白纹伊蚊的平均捕获密度是多少？"
         │
         ▼
 ┌────────────────────────────────────────────────────────┐
 │ 1. 语义意图理解与 Schema 映射 (LLM Prompting)          │
 │    • 实体提取: 时间(2024-07)、城市(郑州)、区(金水)、物种(白纹伊蚊)
 │    • 指标提取: AVG(capture_count)                      │
 └───────────────────────┬────────────────────────────────┘
                         │
                         ▼
 ┌────────────────────────────────────────────────────────┐
 │ 2. SQL 安全拦截网关 (Security Guardrails)              │
 │    • 严格限制只允许 SELECT 查询，拦截 INSERT/UPDATE/DROP │
 │    • 自动添加 LIMIT 1000 防止全表巨量扫描内存溢出        │
 │    • 强制参数化与 SQL 防注入过滤                       │
 └───────────────────────┬────────────────────────────────┘
                         │
                         ▼
 ┌────────────────────────────────────────────────────────┐
 │ 3. 高性能执行与数据结构化适配                          │
 │    • 命中底层索引: idx_monitoring_loc_date             │
 │    • 格式化为前端 AG-UI 可视化图表或透视表格            │
 └────────────────────────────────────────────────────────┘
```

### Text2SQL 编译示例

* **提问**：“查询郑州市各区县上个月诱蚊灯法捕获总数排名前三的区域。”
* **编译生成的标准 SQL**：
  ```sql
  SELECT 
    l.district,
    SUM(f.capture_count) AS total_captured,
    ROUND(AVG(f.weather_temp), 1) AS avg_temp
  FROM fact_monitoring f
  JOIN dim_location l ON f.location_id = l.location_id
  JOIN dim_method m ON f.method_id = m.method_id
  JOIN dim_date d ON f.date_id = d.date_id
  WHERE l.city = '郑州市'
    AND m.method_name LIKE '%诱蚊灯%'
    AND d.year = 2026 AND d.month = 7
  GROUP BY l.district
  ORDER BY total_captured DESC
  LIMIT 3;
  ```

## 二、 国家标准知识库 (GB/T / WS/T) 语义检索

系统在 `app_business.db` 的 `biz_kb_standards` 中内置了权威国家标准与消杀规范，涵盖：
1. **`GB/T 23797-2020`** 《病媒生物密度监测方法 蚊类》（诱蚊灯法、布雷图指数 BI、停落指数等）；
2. **`WS/T 467-2014`** 《登革热媒介伊蚊应急控制指南》（ULV 超低容量喷雾、雾滴中径 VMD 10~30μm、Bti 生物灭幼）；
3. **`GB/T 23798-2020`** 《病媒生物密度监测方法 蝇类》（诱蝇笼法、抗药性轮换用药）；
4. **`GB/T 23796-2020`** 《病媒生物密度监测方法 鼠类》（夹夜法、汉坦病毒与出血热综合防控）；
5. **`GB/T 23799-2020`** 《病媒生物密度监测方法 蜚蠊》（粘捕法、氟蚁腙二次连锁中毒灭蟑）。

### 智能问答对话示例

* **提问**：“根据国家标准，登革热防控中布雷图指数 (BI) 达到多少时需要启动应急消杀？”
* **智能体响应**：
  > 依据国家标准 **`GB/T 23797-2020`** 及 **`WS/T 467-2014`**：
  > - **BI < 5**：安全控制范围，传播风险极低；
  > - **5 ≤ BI < 10**：存在传播风险，需启动常规环境卫生清理与积水翻盆倒罐；
  > - **10 ≤ BI < 20**：暴发风险，需启动重点区域药物喷洒与防蚊灭蚊；
  > - **BI ≥ 20 (红色警戒)**：高暴发风险，必须立即启动全域突发公共卫生应急响应，开展超低容量空间喷雾 (ULV) 消杀并连续监测。

## 三、 多模态交互与视觉物种识别

系统提供前端与移动端的多模态交互能力：

### 1. 移动端 AI 拍照物种识别
- 监测员在现场拍摄虫体照片，前端将图片编码为 Base64 发送至 `/api/v1/mobile/detect-species`；
- 模型识别白纹伊蚊、致倦库蚊、三带喙库蚊、德国小蠊、褐家鼠等 10 余种常见病媒物种；
- 输出拉丁学名、识别置信度（如 98.4%）及核心形态特征描述（如“中胸背板中央具醒目单条白色纵纹”）。

### 2. 交互式多模态组件
- **地图图层联动**：通过对话语音或文字控制地图热力图缩放、区县下钻（如“下钻到金水区”）；
- **动态图表生成**：智能体依据返回数据自动匹配 ECharts 双轴消长图、玫瑰图、矩阵图或处置卡片。

## 四、 自动化专题研判报告导出

在调用 `skill_auto_report_gen` 生成专题报告后，系统支持：
1. **富文本 Markdown 预览**：结构化展示监测概况、时空趋势、抗药性研判与应急防控建议；
2. **一键导出 PDF**：通过 `html2canvas` 与 `jspdf` 实现高精度前端排版一键打印与 PDF 下载；
3. **数据一键复制**：一键复制完整 Markdown 公报文本，方便向上级卫生行政部门快速报送。
