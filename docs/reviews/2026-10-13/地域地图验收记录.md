# 地域识别与共同地图验收记录

实施分支：`codex/region-map-collaboration`。独立 worktree 保留用于审阅；源事实库和原业务库未修改。独立整体验证审查完成后进行了同一修复阶段的回归与累计验证，未重复派发审查。

## 已交付行为

- “显示河南省地图”执行独立行政地图技能，清空业务图层和历史数据条件；不依赖监测库配置，也不执行事实 SQL。
- LLM 识别任务、地域、时间、筛选、逐层要求及明确的续问关系。服务器只接受目录候选、可核验原文和受约束的上下文关系。“郑州”绑定为郑州市；县级“新郑市”保持县级，结构化“郑州／荥阳”绑定到郑州市／荥阳市。
- 新请求不默默继承旧年份、市县、类别和方法。澄清续答保留原任务，校验身份、会话修订和15分钟时限。有效草案在剩余预算内经过一次 LLM 语义复核，实际 HTTP 总次数仍最多两次。
- 受控查询、Python 分析、存储查询、快照导出和已冻结后台任务使用服务器范围。同一范围的一次查询可供点位、文字、热力共同使用；不同年份或地域仍分别批准。
- 共同地图支持已有实际点位、标签、数量或点计数视觉热力、区域面、真实扫描圆和实际插值网格；线渲染接受已有真实线几何。未提供管网、河网或采样坐标的技能保留缺项，不虚构拓扑和位置。
- 数量缺值不补1，零值保留；区县中心不能生成采样点热力。指标表达式不随 SQL 列别名变化，比较图层共用量表，数值和分类图例保留来源。
- 所有批准图层均有执行结果，未执行图层不能整体报成功。NO_DATA、几何不足、来源拒绝和算法错误分别处理；独立公共底图可在数据失败时保留。
- 历史空间、表格、会话和已生成 CSV 下载重新校验当前权限，阻止敏感别名及非首列通配符绕过。过时地图弹窗清理，Web/Widget 事件按地图和界面实例隔离。

## 真实模型结果

实际配置模型为 `qwen3.8-27b`。全部句子和会话场景为合成输入，未向模型发送真实患者记录；凭据未写入报告。留出集在首次调用前补齐了已获批准的验收断言，原40条句子没有更改，其结果没有用于继续调优。

|集合|独立句子|重复次数|通过/总次数|完整意图通过率|p50|p95|
|---|---:|---:|---:|---:|---:|---:|
|开发集|128|3|380/384|98.96%|15.62秒|21.84秒|
|首次冻结留出集|40|3|119/120|99.17%|17.57秒|29.77秒|

评分校验合并后地域与排除项、时间、业务筛选、任务关系、底图选项、图层操作、来源能力、逐层范围及当前身份授权。普通分析可声明同一分析结果的地图呈现；只要求实测分布时点位或有真实量值的热力均可；“今年”允许当年范围或截至评估当日，明确全年和明确日期另行严格约束。

开发集同批原始输出保留原评分，因原断言误拒合理分析呈现和当年至今范围而另存重新评分文件，未重写输出或删除失败。4次失败是无法可靠完成结构化输出；留出失败为 `hold-016` 第2次调用，模型多余地要求确认新建地图。它们均返回澄清，没有冒充成功。上述比例是识别和授权验收，不是地图数据覆盖率、科学模型准确率或100%执行保证。

金水区在当前病媒快照中没有完整地域绑定。开发集 `dev-046`、`dev-068` 和留出 `hold-020` 各3次以“来源不可用且阻止读取”验收，不能算作成功生成监测点。该区行政底图和纯文字行政标注可以独立显示。

所有旧评估（包含中断、低分和部分运行）、实际原始尝试与完整评分保存在 [评估归档](evidence/region-intent-evaluations.zip)；当前摘要为 [acceptance-summary.json](evidence/acceptance-summary.json)。

## 实施取舍及其代价

1. 最新实施授权取代原设计稿的“只设计”约束；代价是这次交付包含实际代码和迁移，需审阅后选择集成方式。
2. 监测坐标按用户确认的 WGS84，行政边界按文件声明 EPSG:4490，保留原生声明；没有测绘级转换保证，潜在小量对齐差异需要专业验收。
3. 唯一精确引用允许修正模型字符索引；重复地名仅在整个目录中只有一个身份时允许锚定，同名区县仍拒绝；代价是证据只能约束字面身份，语义判断仍依赖 LLM。
4. 缺少原场景的开发问句和未给透明度数值的修改预期为澄清；修正误要求点图标的标签断言、合理分析地图呈现和当年至今断言，原始输出及旧评分全部保留；错误预期可能掩盖功能缺项，因此可审阅完整断言和失败记录。
5. 显式结构化 SQL 用精确 AST 绑定并进入指纹；自由文本下的已有批准意图不允许另造绑定。代价是保留了显式 SQL 界面，必须继续依靠当前 schema、主体与 TEMP-view 授权。
6. 用户在自动审批拒绝后批准补齐留出断言；补齐发生在首次评估前且未使用留出结果调优。人工断言仍有作者偏差，故句子、场景和全部原始尝试可审阅。
7. 缺少可选底图类型时使用矢量默认值；地图修改保持原数据及底图，明确操作才能改底图。代价是默认样式可能不同于未表达的偏好。
8. 来源映射缺失按阻止读取验收，与识别错误分别报告；代价是识别率不能代表所有地区已有业务数据。
9. 在两次 HTTP 上限内增加语义复核；代价是识别耗时增加，仍保留无法可靠识别时的澄清。
10. 基线输入不足改用原业务库只读备份；代价是完整基线依赖受控输入，CI合成数据不能替代这一基线。

目录只覆盖仓库提供的河南边界，不代表全国目录或实时行政变更。原有科学方法及未实现的管网、河网、地理传播路线保留其限制；本次没有把图形支持描述成专业效果验证。
