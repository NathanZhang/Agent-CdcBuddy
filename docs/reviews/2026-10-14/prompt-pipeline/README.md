# 固化提示词统一智能体链路验收

54/54 项提示词已使用真实配置模型逐项运行，并通过业务结果检查及普通工作台、浮窗内联组件渲染核对。领域分布：病媒13、食源6、环境17、慢病伤害18。详见 [逐项矩阵](matrix.md) 与 [结构化证据](live-verification.json)。

这里的“通过”指统一链路和当前能力边界按预期运行：42项确认OCR暂缓；60、61项返回人工复核状态，61项仍披露正式Iris/MUSE引擎未安装；35、58项打开交互表单后等待用户照片或采样输入。不能据此宣称OCR、WHO完整编码、真实照片识别准确率或专业模型指标已验收达标。短信和APP外部通道不接入。

## 入口与实现

固化提示词或手动输入 → conversation → LLM意图识别和复核 → 主智能体规划与组合技能 → 授权范围内实际执行 → AG-UI工作台／浮窗内联结果 → 有来源的LLM研判 → 会话保存。

- 首页、技能集市推荐和浮窗均只发送提示词。编号只用于展示与核对；生产配置无预设执行步骤，也无提示词精确匹配路由。测试预期仅存在于tests/fixtures。
- 规划阶段允许原生工具调用，汇总阶段解释实际结果；多步骤任务可以继续规划。模型研判失败时明确返回待复核，不把程序摘要算作模型结论。
- 保留全量工作台结果与审计记录，只限制发送给模型的明细预览；修复地域绑定、双语病原名、日期范围及方法参数的证据校验误判，未放开无依据业务数值或越权读取。
- 任务读取返回实际审批、工单、复测、通知与解除规则；报告明确已归档及下载状态；采样表单明确等待用户输入。肿瘤筛查补齐肿瘤队列、区县人口、检出率及标注假设的收益成本比。

## 真实模型证据

隔离数据包为 `.mock-data/requirement-chat`，四源均为脚本生成的合成Mock；没有修改默认数据源或把Mock标为实测。模型为现有配置的qwen3.8-27b。每条证据包含原提示词、意图、实际工具参数与结果状态、LLM响应、研判文本、会话编号和内容哈希。完整工具载荷保留在包内live-vector/foodborne/env/chronic.json及业务审计库；文档中的精简记录保留原文件和各载荷SHA-256。

批量复测使用low effort；50条最终记录显式记录thinking=false，23/42/43/61为早期运行记录，未记录该开关，不能从文件反推其值。浏览器实际点击27及35项时明确开启thinking并使用low effort，分别显示推理过程及模型结论。用户持久环境配置未改变。

同一业务实现的等价技能允许模型自主选择，验收不绑定唯一技能ID或固定顺序。静态兜底、仅输入检查、空结果、没有模型结论均不计为通过。
