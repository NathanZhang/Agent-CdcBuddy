## 部署与使用

1. 备份当前业务库，使用既有部署迁移入口应用第 009 版；手工运行入口为 `node scripts/migrate.cjs`，沿用部署中的 `APP_BUSINESS_DB_PATH`。试点运行仍要求迁移已应用，不能直接跳过迁移启动。
2. 打开 Skills 集市查看实现阶段和验证阶段，病媒领域选择“病媒捕获量滚动回测与季节基线对照”。回测参数必须有明确截止日期与采样方法；历史回测不能作为当前专业准确率承诺。
3. 对话创建图表技能时说明图表类型、指标和单位；创建器生成并校验实际结果字段绑定。编辑已有自定义技能时填写分类/日期、数值、单位，地图另选行政区代码或经纬度及点位主键。表格类型清除图表配置。
4. 旧自定义记录不猜测字段，不自动迁移成图表；运行显示明细和配置提示，补配置后保存即可使用。

## 最终验证与限制

- 前端及服务：480 项通过、1 项真实 LLM 测试因未启用跳过；科学：36 项通过；集成：51 项通过；隔离兼容回归：44 项通过。
- TypeScript、lint、生产构建和 diff 空白检查通过。新增迁移经过幂等、并发和已有业务库迁移路径测试。
- 沙箱内的 HTTP 监听 EPERM 原始失败保留；获准本地监听后完整集成套件通过。该限制不归类为产品认证缺陷。
- 兼容回归只使用源数据库的只读备份，源文件哈希未变化。证据见 [验证汇总](phase-one-evidence/summary.json) 与 [源数据库保护](phase-one-evidence/source-protection.json)。
- 本轮没有实际 LLM 新技能生成或浏览器手工点击验收；图表与目录使用组件渲染、真实 Skill 调用和地图契约验证。专业模型效果与生产负载另行验收。
