# Agent-CdcBuddy 2.0.1 发布说明

发布日期：2026年10月13日。版本：`2.0.1`；标签：`v2.0.1`。

本版本修复“显示河南省地图”及监测点位地图请求，增加LLM地域识别、共同地图和贯穿查询、分析、历史、导出与后台任务的服务器范围授权。

## 主要变化

- 独立行政地图无需监测查询；“郑州”规范化为“郑州市”，省、市、县及明确的续问继承分别校验，新任务清除旧业务条件。
- 地图技能与点位、标注、实测量热力、区域面、扫描圆、实际插值网格共享版本化空间输出；保留每层范围、权限、坐标系、位置精度及来源。来源缺失或失败不能整体声称成功。
- 支持以实际指标映射圆点大小；按真实点位主键汇总平均量、记录次数和日期范围，表格与地图按点位ID联动。Web和Widget的地图事件相互隔离。
- LLM两次HTTP请求预算内识别与复核；明确歧义证据修复，澄清保留原任务及会话修订。未知地域、未知来源版本及未批准的过滤仍阻止执行。
- SQL与Python分析使用只读受控范围；历史来源、会话、CSV下载和冻结任务重新校验主体与权限，防止范围或敏感列绕过。
- 应用界面版本从包元数据生成；生产Compose、部署及镜像验证脚本默认使用2.0.1。

## 验证与限制

分支与合并后主干均通过384项TypeScript测试、32项科学测试、24项集成测试和44项旧基线，以及lint、TypeScript、生产构建；另完成浏览器原句回放。指标圆点请求实际返回143个点位、1875条监测事实记录；所有平均量、次数和日期范围逐点与只读源库核对一致。记录次数不等同独立采样访次。最终发布验证见 [发布验证记录](evidence/v2.0.1-verification.json)。

原开发集98.96%和首次冻结留出集99.17%对应初次地域地图评估版本；人工修复后未重新使用冻结留出集调优，这些比例不能作为本版本提示变更的新评估结果。完整尝试、失败与工程证据见 [地域地图验收](../reviews/2026-10-13/地域地图验收记录.md) 和 [人工验证修复](../reviews/2026-10-13/指标圆点地图人工验证修复.md)。

目录覆盖仓库已有河南行政边界；监测坐标按确认的WGS84，边界保留EPSG:4490声明，没有测绘级转换保证。缺失采样位置、管网、河网或传播路径不生成虚构几何。原54项专业功能仍未全部完成，2.0.0的科学方法和部署限制继续适用。

## 升级

备份独立业务库及存在的checkpoint后应用新增迁移005–007。源事实库继续只读，替换快照需同步审核版本地域绑定；可使用 `DATASET_REGION_BINDINGS_PATH` 指向受控绑定。`LLM_REGION_INTENT_ENABLED=false` 会停止自由文本执行，显式操作和冻结任务继续使用受控范围。生产部署仍需实际来源、组织账户、APP_ORIGIN和模型配置；步骤见 [部署与验收操作手册](../重构部署与验收操作手册.md)。

本次发布不执行远端部署，也不声称已构建2.0.1生产Docker镜像或验证PowerShell远端执行。

本地主干初次测试中，两个未隔离用例触发默认业务库schema迁移并写入3条测试缓存。已保存现场备份、删除这3条确定的测试记录，清理未改变旧业务表内容；新版空schema保留，未恢复原二进制文件。现测试默认写入临时业务库，重跑完整测试后五个本地数据库前后哈希一致。该本地事件不涉及Git发布数据库或远端部署。

发布后GitHub CI发现12项合成夹具覆盖和来源断言问题，使用相同Mock环境在本地重现后，主干补齐了省市县、抗性类别、PCR年份样本，并按登记来源校验实测/Mock标签。修复后384项TypeScript、32项科学、24项集成及空间契约检查通过，原受控快照完整回归也通过；产品行为未变，已发布`v2.0.1`标签保留。

后续CI的384项TypeScript测试通过，科学阶段暴露网格元数据测试读取本地ignored数据库的依赖。该测试改为自带三个点位的小型夹具，验证3×3网格、0.5度间距和实际范围；在不包含本地数据库或.env配置的干净检出中，384项TypeScript、32项科学、24项集成及空间契约全部通过。
