# Agent-CdcBuddy 2.1.0 发布说明

版本：`2.1.0`；Git标签：`v2.1.0`。

本版本将四智能体的54项功能需求验收场景统一为固化提示词入口。推荐点击与手动输入共用意图分析、任务规划、技能执行、工作台或浮窗展示以及基于执行证据的LLM研判，不再按需求编号或提示词匹配直接执行预设技能。

## 主要变化

- 按病媒13、食源6、环境17、慢病伤害18项整理推荐场景，补齐科学模型、配套合成Mock数据与逐项验收脚本。
- 补齐环境离线采样与幂等同步、报告模板及下载归档、审批复测与工单等持久业务流程；移动图片识别接口调用实际图片LLM并保留人工确认。
- 完善死因文本解析、ICD-10三位类目检索、Iris/MUSE接入适配与人工复核，正式引擎不可用时明确标记待复核。
- 修复提示词和业务结果在工作台、浮窗、历史恢复中的展示，完善地域授权、结果证据校验及发送给模型的明细预览。
- 工程版本、部署镜像默认标签与部署文档统一更新为2.1.0。

## 验证与边界

54项提示词已使用真实配置模型运行，并逐项核对业务结果与普通、浮窗组件渲染；另有浏览器推荐点击、浮窗和历史恢复证据。完整结果、测试方式及失败后复测记录见[验收记录](../reviews/2026-10-14/prompt-pipeline/README.md)和[54项矩阵](../reviews/2026-10-14/prompt-pipeline/matrix.md)。

“通过”表示统一链路在当前能力边界内按预期运行：OCR仍暂缓；60、61项保留人工复核，61项尚缺正式Iris/MUSE安装和规则表，不能声称WHO完整规则已验收；图片与采样场景仍需实际输入。短信与APP外部推送未接入。Mock演示及工程测试不能替代专业模型精度、真实照片识别效果或实测医学验证。

发布前追加验证：lint通过；推荐场景、统一会话入口与部署配置共110项测试通过；发布迁移保护6项测试通过；包版本与锁文件一致。历史控制台日志仅规范化空白字符，保留原始测试结果与失败记录。

## 升级

升级前备份独立业务库及checkpoint，通过现有迁移入口应用迁移013、014和此前未应用的迁移。来源数据库及本地密钥不随Git发布；需要演示数据时按[验收说明](../四智能体验收场景与图片识别.md)显式生成隔离Mock包。正式部署仍需配置事实来源、组织账户、模型服务和适用的编码引擎。

本次发布为源码提交和版本标签，不包含远端部署或已构建的2.1.0 Docker镜像。
