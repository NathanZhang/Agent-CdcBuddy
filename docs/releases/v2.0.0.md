# Agent-CdcBuddy 2.0.0 发布说明

发布日期：2026年10月12日。版本：`2.0.0`；标签：`v2.0.0`。

本版本将四域功能统一到实际LLM、真实Skills与AG-UI组成的主线Agent，交付公共内核、可验证计算子集、持久工作流和服务端授权。原54项专业需求尚未全部完成。

## 主要变化

- HTTP与SSE共享主线Agent，工具执行、回答和界面具有同一runId、方法与来源；失败、不足及未实现能力显式返回。
- 移除CopilotKit独立Runtime、占位actions及固定成功兜底；沿用领域React组件并提供标准AG-UI事件。旧`/api/copilotkit`地址接受本项目协议，原CopilotKit客户端需另做适配。
- 病媒使用真实来源，支持实际AR/GBDT捕获预测及回测、IDW、KMeans、近似圆形扫描和PCR两项关联；三个Mock域执行实际查询与限定分析。
- 数据来源只读，SQL具有AST、辖区、敏感列和行数限制；Python具有并发、超时、输出字节预算与取消。
- 本地身份、服务端会话、域/角色/辖区/所有权授权与独立专业审批权限；无默认生产账户。
- SQLite Job、租约、有限重试、审批检查点恢复、幂等工单与站内通知；复测使用真实采集和明确政策。
- Web与Widget共享工作台能力，UI功能操作与聊天历史分离；LLM网关的思考模式约束由适配器处理，错误仍保留失败语义。
- 单镜像四域配置、试点readiness、锁定依赖、质量CI及业务/检查点备份恢复操作说明。

## 验证

最新重构代码发布前通过lint、TypeScript检查、132项TypeScript测试、29项科学测试、19项集成测试和44项兼容回归，兼容回归确认源数据库未变化。合并后的同版本还需通过完整检查和生产构建后才推送标签；发布执行记录见关联Git提交与GitHub质量工作流。

历史真实LLM、病媒回测、四域演示、认证审批和部署证据见 [重构交付与剩余能力](../reviews/2026-10-12/重构交付与剩余能力.md)。历史报告中的测试数量对应当时提交，新版本以本说明和当前CI为准。

## 限制与部署

捕获/记录不等同标准密度；训练拟合不等同未来预测效果；候选簇、字典编码及经验质控均保留方法限制与专业复核要求。Mock输入只能验工程和已实现方法，不能证明真实业务精度。完整LSTM、SaTScan、传播/基因演化、RF/Kriging、DLNM、人口率、寿命表、ROI、OCR、PDF、SSO、外部通知及PostgreSQL/Kingbase驱动不在本版本已交付范围。

生产默认为pilot。部署前配置实际来源快照、独立业务库、组织账户、APP_ORIGIN及LLM凭据；pilot不会自动生成缺失来源。Git不包含数据库、凭据和本地验收状态。升级、账户初始化、Worker、备份恢复见 [部署与验收操作手册](../重构部署与验收操作手册.md)。

数据不足详细诊断与Agent受控Mock生成目前只有 [待审阅方案](../reviews/2026-10-12/数据不足诊断与Agent生成Mock数据方案.md)，尚未实施。
