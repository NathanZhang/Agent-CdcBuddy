## 一、 四智能体协同架构 (Four-Agent Collaborative Design)

CdcBuddy 采用职责分离与多 Agent 协同的设计范式，将疾控业务划分为四大核心领域 Agent：

```
                    ┌─────────────────────────────────────────┐
                    │          Copilot 语义路由中枢            │
                    └────────────────────┬────────────────────┘

├─────────────────────────┤  ├─────────────────────────┤  ├─────────────────────────┤
│• 种群消长 ARIMA 时序预测│  │• 抗药性 ML 判定与分级   │  │• 传播动力学风险指数量化 │
```

### 1. 监测分析智能体 (Surveillance Agent)
- **核心定位**：病媒生物本底生态与时空消长监测。
- **关联技能**：`skill_population_dynamics` (种群动态), `skill_species_composition` (种群构成), `skill_density_forecast` (密度预测)。
- **核心职责**：分析密度波动特征、气象温湿度驱动因子以及物种结构演变。

### 2. 抗药性分析智能体 (Resistance Agent)
- **核心定位**：化学防制药效监控与抗药性发展预警。
- **关联技能**：`skill_resistance_evaluation` (抗药性评估), `skill_resistance_evolution` (耐药基因演化)。
- **核心职责**：计算 LC50/LC95 毒力回归参数、研判抗性等级，模拟未来 1 年 KDR 等位基因突变频率并提出轮换用药处方。

### 3. 风险评估智能体 (Risk Assessment Agent)
- **核心定位**：传染病传播风险综合量化与多维预警。
- **关联技能**：`skill_pathogen_risk` (病原携带), `skill_spatial_early_warning` (空间预警), `skill_alert_push_dispatch` (预警推送), `skill_transmission_risk` (传播风险)。
- **核心职责**：构建“密度 × 病原携带率 × 暴露人群”动力学模型，生成空间克里金热力图并进行多通道分级推送。

### 4. 处置推荐智能体 (Intervention Agent)
- **核心定位**：应急消杀方案生成与处置全流程工单闭环。
- **关联技能**：`skill_disposal_workflow` (处置闭环), `skill_auto_report_gen` (专题研判报告), `skill_mobile_assistant_api` (移动端现场录入与质控)。
- **核心职责**：自动下发处置工单，匹配国家消杀规范（物理清理、ULV 空间喷雾、Bti 生物灭幼），跟踪 48 小时复测指标核销闭环。

## 二、 Python 科学计算算法引擎详解 (`analytics_engine/`)

算法引擎位于 `analytics_engine/` 模块下，统一由 `engine.py` 进行跨进程与接口调度。

| 模块文件名 | 算法/数学模型 | 输入特征 | 核心输出 |
| :--- | :--- | :--- | :--- |
| `population_dynamics.py` | **ARIMA(p,d,q) + 气象外生回归 (ARIMAX)** | 历史月度捕获密度、均温、相对湿度 | 未来 3 个月密度点预测、95% 置信区间上下界、季节指数 |
| `density_gbdt.py` | **梯度提升决策树 (GBDT / LightGBM)** | 气温、湿度、风速、生境类型、月份、降水 | 未来 1~2 个月密度分级预测、各气象特征重要性贡献度 |
| `spatial_interpolation.py` | **普通克里金 (Ordinary Kriging) / IDW** | 18 地市/区县经纬度坐标、离散点监测密度 | 连续网格化空间密度插值、热力等值面、高风险聚类核心区 |
| `pathogen_apriori.py` | **Apriori 关联规则挖掘 + 频繁项集** | 宿主动物种类、病原体 PCR 结果、地理生境 | 支持度、置信度、提升度 (Lift > 1.5) 的高危病原组合 |
| `resistance_ml.py` | **Probit 毒力回归分析 + 决策树分类** | 浓度梯度、校正死亡率、击倒时间 KT50 | 半数致死浓度 LC50/LC95、回归斜率 b、耐药等级（敏感/低/中/高抗） |
| `resistance_evolution.py` | **马尔可夫链 (Markov) + 贝叶斯基因频率模型**| 历史用药轮换频次、当前 KDR 突变频率 | 未来 12 个月抗性基因演化轨迹曲线、突破警戒线 (75%) 预警时间 |
| `species_clustering.py` | **K-Means 聚类 + Shannon-Wiener 指数** | 各生境各物种捕获计数矩阵 | 优势种构成比 ($p_i$)、多样性指数 $H' = -\sum p_i \ln p_i$、均匀度 $J$ |
| `transmission_risk.py` | **SEIR 虫媒传染病传播动力学修正模型** | 病媒密度 ($D$)、病原携带率 ($P$)、人口密度 ($E$) | 综合传播风险指数 $R = f(D, P, E) \in [0, 100]$ 及分项评分 |

## 三、 核心数学模型算法公式

### 1. 种群消长 ARIMA 时序模型
ARIMA 模型公式表达如下：
$$\Phi(B)(1 - B)^d X_t = \Theta(B)\epsilon_t + \sum_{k=1}^m \beta_k W_{k,t}$$
其中 $W_{k,t}$ 为气温与相对湿度等外生协变量，通过自回归与滑动平均消除季节性趋势，实现未来 3 个月的平稳预测。

### 2. Shannon-Wiener 物种多样性指数
物种多样性度量采用 Shannon 公式：
$$H' = -\sum_{i=1}^{S} P_i \ln(P_i)$$
$$J' = \frac{H'}{\ln(S)}$$
其中 $P_i$ 为第 $i$ 种病媒昆虫在群落中的个体比例，$S$ 为总物种数，$J'$ 为物种均匀度指数。

### 3. 综合传播风险动力学指数
风险指数 $R_{\text{trans}}$ 综合考量病媒密度、PCR 阳性率、易感人群与气象适宜度：
$$R_{\text{trans}} = w_1 \cdot \min\left(100, \frac{D_{\text{obs}}}{D_{\text{base}}} \times 30\right) + w_2 \cdot (MIR \times 300) + w_3 \cdot S_{\text{climate}} + w_4 \cdot S_{\text{pop}}$$
系统根据 $R_{\text{trans}}$ 划分三级风险：
- **$R \ge 70$ (严重预警/红色)**：高暴发风险，触发一级应急响应；
- **$40 \le R < 70$ (较重预警/橙色)**：中度传播风险，启动重点区域药物消杀；
- **$R < 40$ (一般预警/黄色/绿色)**：低风险受控状态，实施常规环境治理。

## 四、 数据库访问抽象层 (DAL) 架构设计

系统通过 `IVectorDataProvider` 接口解耦上层分析逻辑与底层持久化引擎：

```typescript
export interface IVectorDataProvider {
  // 监测数据统计
  getMonitoringSummary(filter: LocationFilter): Promise<MonitoringStats>;
  // 时序消长曲线
  getPopulationDynamics(species: string, city: string): Promise<TrendPoint[]>;
  // 抗药性矩阵
  getResistanceMatrix(species: string, pesticide?: string): Promise<ResistanceRecord[]>;
  // PCR 筛查
  getPathogenDetection(pathogen: string, city?: string): Promise<PathogenRecord[]>;
  // 活跃预警查询
  getActiveAlerts(city?: string, level?: string): Promise<AlertEvent[]>;
}
```

针对 SQLite 与生产 PostgreSQL / 人大金仓 KingbaseES 分别实现 `SQLiteProvider` 与 `PostgreSQLProvider`，实现**零业务代码修改平滑切换**。
